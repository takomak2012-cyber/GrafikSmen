# Политика конфиденциальности

**График смен** (`com.grafik.smen`)
Последнее обновление: 4 октября 2026 г.

## Какие данные приложение собирает

Приложение **не собирает и никуда не отправляет** ваши личные данные: расписание смен,
первую смену, отметки дней, цвета календаря и стоимость смен хранятся только на вашем устройстве.

Приложение не использует серверы собственной разработки и не ведёт аналитику
пользовательского поведения.

## Что хранится на устройстве

| Данные | Где хранятся |
|---|---|
| Тип графика, первая смена, ручные отметки дней, цвета календаря, стоимость смен | На устройстве, `grafik_smen_prefs` |
| Отметка «разрешения уже запрашивались», координаты геолокации | На устройстве, `grafik_smen_local` |

Файл `grafik_smen_local` исключён из резервного копирования: координаты не покидают устройство,
а флаг разрешений не переносится на другой телефон.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | Загрузка прогноза погоды |
| `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION` | Определение города по геолокации — по запросу, необязательно |
| `POST_NOTIFICATIONS` | Уведомление о начале смены |
| `SCHEDULE_EXACT_ALARM` | Точный будильник на время смены |
| `RECEIVE_BOOT_REBOOT` | Восстановление будильников после перезагрузки |
| `VIBRATE`, `WAKE_LOCK` | Сигнал и экран при срабатывании |

Геолокация используется только по вашему запросу. Если не выдавать этот доступ,
город можно выбрать вручную из списка 1117 городов России.

## Сторонние сервисы

**Погода.** Запросы отправляются по адресам `api.met.no`, `api.weatherapi.com`
и `api.open-meteo.com`. Эти сервисы получают координаты выбранного города,
чтобы вернуть прогноз. Координаты передаются только при запросе погоды.

**Поиск города.** При поиске в списке используется `nominatim.openstreetmap.org`.
Запрос содержит введённую строку поиска.

**Реклама.** Приложение показывает один баннер рекламной сети Яндекса (РСЯ).
Рекламная сеть использует идентификатор устройства (`AD_ID`) для показа рекламы.
Без рекламы приложение работает, реклама отключается настройками системы.

## Удаление данных

Удаление приложения с устройства полностью удаляет все его данные.
Часть настроек можно сбросить отдельно в настройках приложения.
